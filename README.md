# CobbleSkyblock

Serveur Minecraft **Cobblemon Skyblock** (Java 1.21.1, Fabric).

## Jouer

1. Télécharge le launcher : **[CobbleSkyblock-Launcher.exe](https://github.com/Thozire/CobbleSkyblock/raw/main/launcher/CobbleSkyblock-Launcher.exe)**
2. Lance-le (si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*).
3. Connecte-toi avec ton compte Microsoft qui possède Minecraft Java, puis clique sur **JOUER**.

Java, Minecraft, Fabric et les mods s'installent et se mettent à jour tout seuls.
Comptes premium uniquement.

## Contenu du dépôt

- `pack.toml`, `index.toml`, `mods/`, `resourcepacks/`, `world/` : le modpack (packwiz), synchronisé par le launcher et par le serveur.
- `launcher.json` : adresse du serveur, actus et message affichés dans le launcher.
- `launcher/` : le launcher Windows. `launcher-src/` : son code source (Go).
