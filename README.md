# Serveur MineColonies (ex-CobbleSkyblock)

Serveur Minecraft **MineColonies** entre potes (Java 1.21.1, NeoForge 21.1.267).

## Jouer

1. Télécharge le launcher : **[CobbleSkyblock-Launcher.exe](https://github.com/Thozire/CobbleSkyblock/raw/main/launcher/CobbleSkyblock-Launcher.exe)** (version 2.0.0 ou plus).
2. Lance-le (si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* → *Exécuter quand même*).
3. Connecte-toi avec ton compte Microsoft qui possède Minecraft Java, puis clique sur **JOUER**.

Java, Minecraft, NeoForge et les mods s'installent et se mettent à jour tout seuls.
Le premier lancement installe NeoForge (1 à 2 minutes de plus). Comptes premium uniquement.

## Mods

MineColonies 1.1.1420 et ses dépendances (Structurize, BlockUI, Domum Ornamentum, Multi-Piston),
plus JEI (recettes) et Jade (infos sur ce que tu regardes).

## Contenu du dépôt

- `pack.toml`, `index.toml`, `mods/` : le modpack (packwiz), synchronisé par le launcher et par le serveur.
- `launcher.json` : adresse du serveur, actus et message affichés dans le launcher.
- `launcher/` : le launcher Windows. `launcher-src/` : son code source (Go).
- L'ancien serveur Cobblemon Skyblock est conservé dans la branche [`skyblock`](https://github.com/Thozire/CobbleSkyblock/tree/skyblock).
